# CLI reference

This page indexes the generated CLI reference. Each linked file is one cobra command (plus its subcommands), produced from the binary's own `--help` text by `tools/gendocs/main.go`.

> **Do not edit the generated files by hand.** They are regenerated by `go generate ./...`. Edit the `Short`, `Long`, and `Example` fields on the cobra commands instead; the published page picks up the change on the next generate.

## Regenerate

```bash
go generate ./...
```

The `go:generate` directive lives on `pkg/cmd/root/root.go` and points `tools/gendocs` at this directory.
