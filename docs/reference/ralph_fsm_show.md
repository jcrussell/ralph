## ralph fsm show

Pretty-print .ralph/state/fsm.json

```
ralph fsm show [flags]
```

### Examples

```
  ralph fsm show
  ralph fsm show --json | jq .
```

### Options

```
  -h, --help   help for show
      --json   emit raw fsm.json
```
